## How To Study

1. **Basics pehle padho** - `00-BASICS.md` file har topic mein hai
2. **Brute force samjho** - Pehle simple solution, phir optimize
3. **Dry run karo** - Paper pe trace karo
4. **Run karo** - `node path/to/file.js`
5. **Revise karo** - `QUICK-REVISION.md` se interview se pehle
